# 管理界面连接主机

management.json 增加 `host_ip`，默认 `10.0.0.2`。旧配置未指定该字段时使用默认值，点击保存并连接会写入 JSON。

从机模式：管理界面只访问本机从机（Android Binder；Windows/Linux 127.0.0.1:19528）。本机从机按照请求中的 host_ip 向主机19526发送CLDC管理注册；主机主动连接从机9527。后续请求经该CLDC连接传送，管理界面不访问远端19527。

主机模式：管理界面访问本机127.0.0.1:19527，不使用远端IP。

主机仍只接受 host.json 中已配置从机的注册，设置主机IP不会自动信任未知从机。目标主机需运行、19526可达，并能够反向连接从机9527。注册成功代表管理会话激活，不代表所有后续命令已经执行。

Android需同时更新管理界面1.1.9和从机0.5.25；旧从机会忽略目标IP。Windows/Linux从机需要包含本次更新的management_bridge.py。
