# 独立安卓管理界面 1.1.0

2026-10-09：原“主机Codex界面”升级为“LLM对话界面”，选择Codex/DSH/OpenCode后，展示主机返回的会话列表，支持继续和新建。SEND/STOP直接经主机内置模块调用本地API，不依赖桌面键盘注入。界面没有模型/登录设置；用户预先在主机配置。需更新安卓从机0.5.21以允许新的llm_*操作。完整设计、配置、验证和限制见[LLM_API.md](../host_program/LLM_API.md)。以下保留旧版本变更记录。

下载：`http://10.0.0.2:18765/cloud-management-1.1.0-debug.apk`；从机：`http://10.0.0.2:18765/cloud-android-slave-0.5.21-debug.apk`。

1.0.5：Codex页参考原从机“打开当前窗口”：深色背景、顶部白色输入框、SEND/STOP、等宽文本和常显滚动条；删除底部常驻请求/空闲状态行，操作结果使用短暂提示，完整诊断保留运行日志。触摸浏览历史时暂缓文本更新，不重置阅读位置。搭配从机0.5.17，旧“打开当前窗口”入口、Activity、状态类及0603/0604处理已删除；独立管理队列0602/0606和日志诊断0605保留。

1.0.4新增持久运行日志，原始文件在应用files/share/management_ui.log；搭配从机0.5.16，主机读取诊断时同步到从机公共shared目录management_ui.log。完整路径及记录字段见[运行日志说明](../docs/dev/management_android/RUNTIME_LOG.md)。首页版本改为构建版本，避免旧硬编码误导。下述1.0.3为通信方式改动记录。

1.0.3将安卓同设备通信改为签名权限保护的ContentProvider.call（Binder），移除从机本地TCP19528监听。旧版跨应用请求超时、从机自身自检正常，具体TCP根因尚未确认。较大返回内容经ParcelFileDescriptor管道传递，避免截图超过Binder事务容量。设置中的本机健康检测也走Binder，不发送文字或ESC。此版编译通过，尚待更新两份APK后真机验收。

包名 `com.cloudpc.management`，与安卓从机并存。仅管理界面，无从机9527、WireGuard、音频、声纹或Codex执行逻辑。使用已有WireGuard连接，不覆盖原配置。

首页三个业务入口：从机界面1、从机界面2、主机Codex界面。点击首页标题设置本机角色与两个从机IP，未配置槽位明确提示。

默认“从机设备”，界面只访问同设备从机content://com.cloudpc.androidslave.management，经主机已建立的CLDC连接取得信息。Provider显式检查同签名权限。选择“主机设备”时只访问本机主机127.0.0.1:19527。旧url/token偏好升级时清除，不需要远程主机地址与令牌。填写的从机IP只作为主机的管理目标，界面不会连接该地址。

先更新并启动安卓从机0.5.15，再打开独立管理界面1.0.3。管理界面不直连远程主机、目标从机或Codex适配器。原内置“当前窗口”CLDC路径保持不变。

主机仅保留回环19527，上一轮新增远程入口与令牌参数已撤销。从机将本机请求加入0602/0682事件队列，由主机处理current/send/stop/slaves/screenshot，通过0606/0686按同一请求ID返回。从机不主动连接主机，超时/断线明确报错，不自动重发操作。

Codex页输入在顶部，键盘弹出adjustResize；文字每秒按需读取，最多由适配器保留500行/约64K字符。首页、后台不读取。首次跟随最新内容；浏览历史时刷新不改变像素滚动位置。SEND生成唯一ID，一次请求不重试，失败保留输入。STOP忙碌门控由独立适配器执行。截图页面1秒请求，上一请求未完成不堆积，错误标注旧内容已过期。

构建：Java17、Android SDK36、Gradle8.11.1；执行 `gradle --offline --no-daemon :app:assembleDebug`。产物 `dist/cloud-management-1.0.3-debug.apk`，真机交互待更新两份APK后验收。

# 1.1.5 更新

管理设置和上次会话改存应用文件目录 `management.json`。首次生成默认值并迁移旧偏好，之后以 JSON 为准；保存及选择会话更新同一文件。连接设置中显示实际路径，坏文件不覆盖。APK 覆盖安装保留，卸载/清除数据不保留。

# 1.1.4 更新

LLM 选择页新增“返回上次对话”，成功打开会话后持久保存提供商及会话 ID，退出应用后仍可恢复。不新建会话、不重新发送消息；会话无效时显示主机错误并保留会话列表入口。升级后首次需正常打开一次会话才能保存记录。

# 1.1.3 更新

SEND/STOP 的编号及提交结果固定显示在 Working 下方，不再弹 Toast；下一次操作替换上一条结果。对话页移除底部额外 64dp 留白，扩大正文区，系统导航栏安全区域保留。

# 1.1.2 更新

根据真机截图修正 Working 状态文字的颜色：明确设置浅蓝色，避免主题默认黑字在深色背景下不可辨认。

# 1.1.1 更新

LLM 对话界面工作期间显示 `Working（秒数s）`，空闲时隐藏。不显示连接诊断文字，不改变正文滚动位置。需配套支持 `working_seconds` 的主机；旧主机返回缺省值 0。

# 1.1.8 更新

对话按消息分段显示，长内容默认约四行正文加省略号，点击各段“展开／收起”查看完整内容；只改变显示，不截断 API 数据。展开状态在本次会话页面刷新时保留。截图页增加顺时针旋转90°，四次恢复原方向，后续每秒截图更新保持角度，退出页面后重置。主机及安卓从机不需要更新。
