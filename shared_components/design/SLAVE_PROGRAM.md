# 从机程序分项设计

上级文档：[总体设计](../DESIGN.md)。本文是目标设计，不是已完成清单。

实现进度（2026-10-06）：Python 从机已支持带编号的 file.list/file.stat RPC，并提供已有主机会话上的转接请求接口；真实 TCP 双向转接已验证。UWP/Android 尚未移植，设备安装包未更新，主机身份认证仍未完成。

## 1. 职责与通信边界

从机监听配置的服务入口，等待主机主动连接。认证成功后，只接受授权主机的指令。

从机不主动连接其他从机，也不接受其他从机的直接通信。对主机发送结果、事件、采集数据和转接请求，均使用主机建立的会话或主机协商的媒体通道。

2026-10-07例外：管理界面首次激活时，由本机从机向预先已知的主机19526主动发送CLDC注册通知；主机再主动建立/保持业务连接。该短连接只支持激活和释放，不用于任务、媒体或从机间直连。Android从机默认主机10.0.0.2，并保存正常主机会话的来源地址；Python从机用CLOUD_MANAGEMENT_HOST/CLOUD_MANAGEMENT_PORT配置首次注册地址（默认10.0.0.2:19526），已连接主机时采用真实主机来源地址。

功能总览：接受授权主机连接；执行本地文件、任务及应用转发指令；按主机要求采集截图和音频；返回结果和事件；将跨从机消息提交主机转接；报告本机能力、权限限制和错误。

## 2. 指令执行

从机根据平台能力和权限执行：

- 文件列表、读取、上传及经授权的文件修改。
- 任务执行、状态查询、输出读取和取消。
- 屏幕截图、音频等采集。
- 向同设备应用转交经授权的业务请求。
- 返回能力、操作结果、事件和错误。

Windows、Android 和 HoloLens/UWP 的系统权限不同。UWP 沙箱、Android 存储权限及麦克风权限不会因为协议统一而消失。不支持的功能应明确返回错误，不能假装成功。

文件访问应校验规范化后的目标路径及授权根目录；不得用简单字符串前缀比较代替路径边界检查。

## 3. 转接请求

从机需要与另一从机通信时：

1. 请求方事先知道目标 IP。
2. 在已认证的主机会话上发送目标 IP、操作及正文。
3. 等待主机返回目标执行结果或转接错误。

从机不自行扫描其他设备，不向主机自动报告其网络下设备的 IP，不自行建立到目标从机的连接。

收到主机转发的消息时，仍以主机的授权和本机权限为执行依据。附带的原始来源仅用于业务与审计，不表示允许该来源直接连接。

## 4. 活动采集

启动从机本身不代表开始截图或录音。主机设置活动并下发采集配置后，从机才开始对应同步。

取消活动、主机会话失效或主机要求停止时，停止相应采集；释放不再需要的设备资源。重连后等待主机重新确认配置，不擅自恢复无人授权的录音。

返回数据应包含来源、采集时间、序号和媒体格式。设备不支持或未获得权限时，向主机报告原因。

## 5. 本地应用接口

ALXR、UE 或其他应用的本地接口与云电脑网络入口是不同边界。

同设备应用可以使用经授权的本地 IPC 或回环接口；具体平台是否允许应用互通需要实测和适配。该接口不得变为其他从机绕过主机的网络入口。

业务数据若需发送到另一台设备，仍经主机转接。现有直接发送到远端从机的实验代码需要后续迁移。

## 6. 安全与诊断

从机必须验证主机身份、操作权限、参数及载荷边界，并拒绝未经授权的连接。WireGuard 或局域网可改善网络可达性，但不能单独证明连接者是授权主机。

记录认证、指令、采集启停和本地应用转交结果。错误返回主机，由主机统一展示给管理界面。
