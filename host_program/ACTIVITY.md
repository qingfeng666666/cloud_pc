# 简略主机运行状态

管理界面新增“主机运行状态”，每秒按需读取，最新在上、最多500条内存记录。字段为时间、IP、动作、状态；命令执行只记录可执行文件名，不记录参数、输入正文、文件内容或密钥。

主机记录连接中/已连接/失败/断开/重连耗尽、执行命令、文件查询与传输、截图、UE及设备转发请求。长请求区分进行中与完成/失败/超时/中断。协议事件轮询、健康检查和运行状态读取自身不记录，避免递归产生记录。重启清空界面记录，既有云电脑主机日志仍保存简略行为行。

GET /api/management/activity返回connections、active、records、revision。安卓界面1.0.6通过本机从机0.5.18 Binder操作activity，经既有CLDC0602/0606取回；Windows/Linux从机管理桥也支持同操作，不新增对外端口。

Windows/Linux管理界面源码已增加入口；旧Windows EXE不会自动获得新页，需要重新构建。

2026-10-07：管理读取现在需要已激活的会话。记录新增“激活管理界面”“关闭管理界面”“管理从机重连策略”；日志不记录会话标识。主机仅对活动管理从机每5秒持续重连，注册通知走19526 CLDC白名单入口，业务仍走既有9527连接。
