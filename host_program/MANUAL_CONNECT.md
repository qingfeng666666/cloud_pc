# 主机手动连接

主机启动按配置主动连接，自动重试仍为原有限次数；次数耗尽后客户端保留在配置中，可手动启动新一轮连接，不重启整个主机。

在工程根目录执行：

`python3 -m cloud_pc.host_program.connect_slave 192.168.4.20:9527`

命令只调用同设备主机127.0.0.1:19527。接口为POST /api/<已配置从机ID>/connect，正文{}。不接受任意未配置IP，不由命令脚本直接建立从机连接，不新增端口。返回started=true表示开始连接，不表示握手已完成；GET /api/slaves查看connected。

已经在线或正在连接返回started=false，不重复建连接。仅首次部署此代码需重启旧主机进程；以后正常操作不需重启。Linux启动命令与Windows打包源码均已同步。
